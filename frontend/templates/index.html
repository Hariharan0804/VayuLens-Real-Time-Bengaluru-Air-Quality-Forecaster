Project Overview

VayuLens — Real-Time Bengaluru Air Quality Forecaster

VayuLens is an intelligent environmental telemetry platform designed to reframe civic atmospheric monitoring in Bengaluru. Combining live OpenAQ API synchronization, machine learning forecasting, and intuitive telemetry visual designs.
